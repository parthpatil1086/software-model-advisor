# 🛠️ Software Model Recommender & Budget Estimator

A smart web app that helps software engineers and clients decide the most suitable **software development model**, estimate project cost, and get optimization suggestions — all in one platform.

## 🔍 Features
- Multi-page input form
- Smart suggestion of Waterfall / Agile / V-Model etc.
- Estimated cost based on project parameters
- Budget analysis and tips to reduce cost
- PDF quotation generator
- Clean interface using Streamlit

## 🚀 Technologies Used

- Python 3
- Streamlit
- ReportLab
- Pandas

## 📦 Deployment
Can be deployed on:
- [Streamlit Cloud](https://streamlit.io/cloud)
- Render
- GitHub Pages (via iframe)

## 🙋‍♂️ Use Case

Used as an **Industrial Training Project (ITER)** to demonstrate practical software project planning, estimation, and AI-assisted model suggestion.
